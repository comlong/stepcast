# StepCast

[English](README.md) | **中文**

本地运行的教学视频生成器。在 Chrome 里正常操作一遍（或者丢一份 PPT 进来），自动产出一段**带解说、配音、字幕、鼠标动画和操作高亮**的 MP4 教学视频。

全部数据留在本机：语音识别在本机跑；只有生成解说、翻译、AI 改写、生成第二语言字幕（以及幻灯片「逐条出现」的对齐）会调用你选的大模型（DeepSeek / OpenAI / Claude / Mistral / Gemini / Azure / 国产模型，或本地 Ollama），见[隐私说明](#隐私说明)；「AI 配音」默认用微软 Edge 的免费语音服务。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| 捕获浏览器操作 | Chrome 扩展记录点击 / 输入 / 回车 / 页面跳转，并在每一步自动截图 |
| 识别操作对象 | 记录被点元素的文字、角色（按钮 / 链接 / 输入框）、位置矩形 |
| 自动写解说 | 大模型根据操作序列生成视频标题、片头、每一步旁白和字幕；DeepSeek / OpenAI / Claude / Mistral / Gemini / Azure OpenAI / 本地 Ollama 任选 |
| 语音合成 | edge-tts 神经网络语音（免费），中英日韩等 40+ 语言、300+ 音色；也可以换成豆包、MiniMax、通义、Google Gemini、ElevenLabs、Azure 的付费配音 |
| 语音输入 | **边录边讲**（操作时讲解，自动分配到每一步）、单步录原声、上传音频、口述转文字 |
| PPT / PDF 转视频 | 每页一个步骤，**解说说到哪条、页面上哪条才出现**，**页面里的视频原位播放**；**演讲者备注原文直接作解说**（也可交给 AI 参考改写），可选页、选详细程度 |
| 两人问答 | PPT 可以做成**主持人和讲师对话讲解**的视频：两种音色，内容不压缩，像两个同事在聊 |
| 高亮用户动作 | 目标区域描边 + 呼吸脉冲 + 背景变暗 + 点击涟漪 + 鼠标飞入动画 |
| 自动运镜 | 缓动推近到操作区域，结束时拉回全景 |
| 字幕 | 烧录进画面，同时导出 `.srt` / `.vtt` |
| 第二语言字幕 | 渲染后一键生成一种或几种语言（中文、30 多种欧洲语言等 46 种）的外挂字幕，紧贴在主字幕下面、默认斜体；导出网页播放包，看的人自己选第二字幕（默认不显示） |
| 敏感信息打码 | 录制时自动识别邮箱 / 手机号 / 身份证 / 银行卡 / IP / 人名并模糊；也可手动框选 |
| 翻译 | 一键把整套脚本换成其他语言并换成对应音色重新配音；PPT 项目按原文直接用目标语言重写，不翻译现有解说 |
| 脚本编辑 | 网页编辑器里改文案、调高亮框、调顺序、删步骤、单步试听、AI 改写 |
| 导出 | MP4 视频、SRT 字幕、Markdown 图文文档、脚本 JSON |

## 安装（3 步）

### 1. 装好依赖

双击 **`setup.bat`**（会自动建 `.venv` 虚拟环境并安装依赖）。

或者手动：

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

要求 Python 3.10+。

**ffmpeg**：建议装一个（速度快、功能全）：

```bash
winget install Gyan.FFmpeg
```

没装也能跑 —— 会自动回退到 `imageio-ffmpeg` 附带的版本。

### 2. 启动服务

双击 **`run.bat`**，或：

```bash
python app.py
```

浏览器会自动打开编辑器 <http://127.0.0.1:8756/>。

### 3. 装 Chrome 扩展

1. Chrome 地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目的 `extension` 目录

浏览器右上角出现橙色 ▶ 图标即安装成功。

## 打包成 exe 发给同事

同事的电脑不需要装 Python、ffmpeg 或任何库。

### 打包

双击 **`build_exe.bat`**（第一次会往 `.venv` 里装 PyInstaller，打包大约几分钟）。产物在 `dist\`：

```
dist\
├── StepCast\                         整个文件夹就是软件
│   ├── StepCast.exe                  双击运行
│   ├── _internal\                    所有库：Python、ffmpeg、语音识别、PPT/PDF 解析……（不要删）
│   ├── extension\                    Chrome 扩展，在 chrome://extensions 里「加载已解压的扩展程序」选它
│   └── README.txt                    英文、中文使用说明
└── StepCast-<版本>-win64.zip          把这个压缩包发给同事（约 170 MB）
```

打出来的是「exe + 文件夹」，不是单个 exe：依赖有几百 MB，单文件 exe 每次启动都要先解压到临时目录，启动慢，也更容易被杀毒软件误报。

你自己的 `config.json`（有 API Key）和 `projects\` **不会**被打进去，打包脚本会检查。

**给国内同事**：在命令行运行 `build_exe.bat --with-model`，会再多打一个带语音识别模型的压缩包（`…-with-model-small.zip`），同事那边不用下载模型（见「[在中国大陆 / 公司网络下载不了模型](#识别模型)」）。

### 同事怎么用

1. 解压到任意位置（桌面、D 盘都行，路径里有中文、空格也没关系），双击 `StepCast.exe`
   - 会开一个命令行窗口，**不要关**，关掉服务就停了；浏览器自动打开编辑器
   - 第一次运行 Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（exe 没有数字签名）
   - 再双击一次不会重复启动，只会重新打开编辑器
2. Chrome 里加载 `extension` 文件夹（同上面「装 Chrome 扩展」）
3. 编辑器右上角 ⚙ 设置里选 AI 服务商、填自己的 API Key。界面默认是英语，可在右上角切换

### 数据存在哪里

| 内容 | 位置 |
|---|---|
| 所有项目（截图、配音、生成的视频） | exe 旁边的 `projects\<项目id>\` |
| 生成的视频 / 字幕 | `projects\<项目id>\output\` |
| 上传的 PPT / PDF | `projects\_imports\`（生成项目后 48 小时自动清理） |
| 设置和 API Key | exe 旁边的 `config.json` |
| 编辑器里点「下载 MP4」 | 浏览器的下载文件夹 |
| 语音识别模型（第一次用时下载，约 465 MB） | `%USERPROFILE%\.cache\huggingface` |

如果 exe 所在的文件夹没有写入权限（比如放进了 `C:\Program Files`），`projects\` 和 `config.json` 自动改存到 `%LOCALAPPDATA%\StepCast`。启动时命令行窗口会打印实际的项目文件夹。

**升级**：解压新版本，把旧文件夹里的 `projects` 和 `config.json` 拷过去即可。

**需要联网**：配音（微软 Edge 语音）和 AI 生成解说要联网；语音识别在本机跑，模型下载好之后不需要联网。

## 界面语言

编辑器右上角 **⚙ 设置** 左边的下拉框切换工作语言：**中文 / English / Deutsch / Français / Polski / Italiano / Español / Nederlands**，选完页面自动刷新。

- **Chrome 扩展**跟着同一个设置走：弹窗、录制浮层、麦克风设置页在连上本地服务时自动换成相同语言（服务没开时沿用上次的语言）。扩展的名称和快捷键说明跟 Chrome 自身的语言
- **默认英语**：全新安装（或者配置里没选过界面语言）时界面是英语，解说语言是英语（en-US），音色是 en-US-AriaNeural。选过的语言会记住
- **报错和进度提示**（后台任务、AI 服务商、语音识别等）也跟界面语言
- **界面语言 ≠ 解说语言**：解说语言在 ⚙ 设置 → AI 与语音里单独选（见下面「解说语言和第二字幕语言」）。写进视频和文档的默认文字（比如图文文档里的「步骤 3」、没写片尾文案时的「完成！」）跟项目的解说语言走，不跟界面语言

> 敏感信息打码的自动识别规则目前偏向中文页面：手机号、身份证按中国格式识别，带标签的人名只认中文和英文标签（「姓名：」「Name:」「Contact:」等），「裸的中文短名」只针对中文人名。邮箱、IP 和你自己填的关键词对所有语言都有效 —— 录欧洲系统时建议把客户名等填进「额外要打码的词」。

**维护翻译**：代码里的界面文字写中文原文并包在 `t()` 里，译文在 `static/locales/{语言}.json`。改了文字后运行：

```bash
python tools/i18n_extract.py
```

它会列出没包 `t()` 的中文、各语言缺的译文、占位符或 HTML 标签对不上的译文。补完后加 `--sync-extension` 把扩展用到的部分复制到 `extension/locales/`。数量用 ICU 复数写法，例如 `{n, plural, one {# step} other {# steps}}`，波兰语还有 `few` / `many`。

## 配置 AI 模型

生成解说、翻译、AI 改写要用一个大模型。打开编辑器右上角 **⚙ 设置 → AI 与语音**，选服务商、填 API Key、选模型，点 **测试连接** 确认可用后保存。

| 服务商 | 协议 | 数据在哪处理 | 说明 |
|---|---|---|---|
| **DeepSeek** | OpenAI 兼容 | 中国 | 默认；老版本的配置自动沿用 |
| **豆包（火山方舟）** | OpenAI 兼容 | 中国 | 默认 `doubao-seed-2-1-pro-260628`；模型 ID 在方舟控制台「模型广场」复制，要先开通；自动关掉深度思考 |
| **通义千问（阿里云百炼）** | OpenAI 兼容 | 中国（北京地域） | 默认 `qwen-plus`；自动关掉思考模式 |
| **智谱 GLM** | OpenAI 兼容 | 中国 | 默认 `glm-5`；自动关掉思考模式 |
| **MiniMax** | OpenAI 兼容 | 中国 | 默认 `MiniMax-M3`；模型总是先思考再回答，慢一些（思考内容会自动去掉）；国内接口地址是 `api.minimax.cn` |
| **OpenAI** | OpenAI 兼容 | 美国 | 默认 `gpt-5-mini` |
| **Claude（Anthropic）** | 官方 SDK | 美国 | 默认 `claude-opus-5`（质量最好）；`claude-sonnet-5` 更快更便宜 |
| **Mistral AI** | OpenAI 兼容 | **欧盟**（法国公司，以官方条款为准） | 默认 `mistral-large-latest` |
| **Google Gemini** | OpenAI 兼容 | 美国 | 免费档的数据可能被用于改进模型 |
| **Azure OpenAI** | OpenAI 兼容 | **可选欧盟**（欧洲区域资源 + EU Data Zone 部署） | 接口地址填 `https://资源名.openai.azure.com/openai/v1`，模型填部署名 |
| **本地 Ollama** | OpenAI 兼容 | **本机，不联网** | 质量取决于模型和电脑配置；先 `ollama pull qwen3:8b` |
| **其他 OpenAI 兼容接口** | OpenAI 兼容 | 看服务商 | OpenRouter、LM Studio、vLLM、Scaleway、IONOS…… 填接口地址和模型名 |

- **模型**可以手填，也可以点「获取模型列表」从服务商那里拉最新的列表
- **测试连接**：Claude 只查询模型信息，不花 token；其他服务商发一句很短的测试
- 各家的 Key 分开保存，切换服务商不会丢；留空保存 = 保持原来的 Key
- 不同模型不认的参数（`temperature`、`max_tokens`、JSON 模式、关思考的参数）会自动调整后重试，不用手动配
- Claude 的 `claude-opus-5` / `claude-fable-5-1` 默认开启服务端兜底：极少数请求被安全策略拒绝时，Anthropic 会自动换一个模型重跑

也可以用环境变量，优先级高于界面里填的：

```bash
set DEEPSEEK_API_KEY=sk-xxxxxxxx
set ARK_API_KEY=xxxxxxxx
set DASHSCOPE_API_KEY=sk-xxxxxxxx
set ZHIPUAI_API_KEY=xxxxxxxx
set MINIMAX_API_KEY=xxxxxxxx
set OPENAI_API_KEY=sk-xxxxxxxx
set ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
set MISTRAL_API_KEY=xxxxxxxx
set GEMINI_API_KEY=xxxxxxxx
set AZURE_OPENAI_API_KEY=xxxxxxxx
```

Key 保存在本机 `config.json`，界面和接口只显示掩码，不会上传到任何地方（只发给你选的那家服务商）。

> 在欧洲、介意数据出境：选 **Mistral** 或 **Azure OpenAI（欧洲区域）**；数据要留在国内：选 **DeepSeek / 豆包 / 通义 / GLM / MiniMax**；完全不想外发：选 **本地 Ollama**。

### 更多配音服务（可选，付费）

默认用 Edge 的免费配音。想要更自然的声音，在 **⚙ 设置 → AI 与语音 → 配音 → 更多配音服务** 里填 Key，这家的音色就会出现在所有「配音音色」下拉框里（名字前面带服务名），项目音色、两人问答的两位讲者都能选，可以混着用：

| 服务 | 特点 | Key |
|---|---|---|
| **豆包语音（火山引擎）** | 中文最自然的一档；自己复刻的声音（`S_` 开头的音色 ID）可以在设置里加进来 | 火山引擎「豆包语音」控制台开通语音合成大模型 2.0，在「API Key 管理」里创建（新版控制台） |
| **MiniMax 语音** | 中英文都很自然，音色多（有 Key 时从接口取完整音色表，包括你复刻的） | 和「AI 模型」里的 MiniMax 同一个 Key，那边填过就不用再填 |
| **通义语音（阿里云百炼 Qwen-TTS）** | 一个音色能说中文、英文等十种语言 | 和「AI 模型」里的通义千问同一个 Key |
| **Google Gemini 语音** | 一个音色能说一百多种语言，共 30 个音色；可以用文字描述语气（**语气提示**）；两个模型（Flash TTS，或更便宜的 Flash-Lite TTS） | 和「AI 模型」里的 Google Gemini 同一个 Key；欧洲使用需要付费档（在 Google AI Studio 里绑定结算账号） |
| **ElevenLabs** | 公认最自然、最有表现力，音色库很大，英语和欧洲语言尤其好；模型有 Multilingual v2 / v3 / Flash v2.5 | 网站 API Keys 页面创建；免费档每月 1 万字符 |
| **微软 Azure 语音** | 和 Edge 免费语音是同一套声音，另有更自然的 HD 语音；有欧洲区域，每月有免费额度 | 在 Azure 门户创建「语音服务」资源，复制 Key，并在设置里填资源所在的区域（如 `westeurope`） |

- 点「测试」合成一句试试 Key 对不对（不保存；会产生极少的费用）
- 长段落按句子切成几段分别合成再拼起来，每段的时间用来对齐字幕和逐条出现
- 出错（Key 不对、余额不足）会直接报出来，不会悄悄换成 Windows 的机器音
- 配音文字会发给对应的公司；环境变量 `MODEL_SPEECH_API_KEY`（豆包）、`MINIMAX_API_KEY`、`DASHSCOPE_API_KEY`、`GEMINI_API_KEY`（或 `GOOGLE_API_KEY`）、`ELEVENLABS_API_KEY`（或 `XI_API_KEY`）、`AZURE_SPEECH_KEY` 也认
- 这些服务都不返回逐词时间，所以长段落里的字幕和逐条出现是按分段（几句话一段）对齐的，不是逐词
- **配音文字要留在欧洲**：选 Azure 的欧洲区域（如 `westeurope`），或者 ElevenLabs 的 **数据区域 → 欧盟**（要企业档）；Gemini 没有区域设置
>
> 不配 Key 也能用：自己在编辑器里逐条写解说词，一样可以配音和出视频。

> 从旧版本升级：Claude 需要新依赖，重新双击 `setup.bat` 或执行 `pip install -r requirements.txt`。

## 使用流程

```
点扩展 → 开始录制 → 正常操作网页 → 停止 → 编辑器里改脚本 → 一键生成 → 拿到 MP4
```

**1. 录制**

点扩展图标，填个教程名称，点「开始录制」。然后像平时一样操作网页即可。页面右下角会出现一个「● 录制中」小浮层（截图时会自动隐藏，不会进画面）。

- `Alt+Shift+R` 开始 / 停止录制
- `Alt+Shift+S` 手动补一张截图（用于记录纯展示、没有点击的画面）

点浮层或扩展里的「停止」，会自动打开编辑器。

**2. 编辑**

- **左栏**：最上面是**片头**卡、最下面是**片尾**卡，中间是录到的步骤（可拖动排序）
  - 点「片头」改视频标题、副标题、片头旁白，或直接取消勾选「视频包含片头」
  - 点「片尾」改结尾那句话；不想要片尾就**取消勾选「视频包含片尾」**（文案会保留，之后「生成解说」「一键生成」也不会把它加回来，勾回来即恢复）
  - 想让所有新项目默认都不带片头 / 片尾：⚙ 设置 → 视频风格 → 取消「生成片头」「生成片尾」；单个项目里的勾选优先
  - **片头 / 片尾换成自己的画面**：右侧「背景画面」→ 上传一张图片，或者一份 PPT / PDF 再选其中一页（比如公司统一的封面页、结束页）。可以选「完整显示」（空出的边用模糊背景补齐）或「铺满画面」、要不要在上面叠标题 / 片尾文字（上传 PPT / PDF 时默认不叠，页面上一般已经有字），以及停留几秒（不会短于那段配音）。片尾有背景图时不写文案也行，结尾只显示那一页
  - PPT 要转成图片需要本机装有 PowerPoint 或 LibreOffice；都没有的话把那一页另存为 PDF 或图片再上传。PDF 和图片随时可用
  - 没有上传背景时用默认的渐变背景，配色和分辨率在 ⚙ 设置 → 视频风格 里调
- **中间**：拖动橙色框可以调整高亮区域；切到「渲染预览」看视频里的真实画面
- **右栏**：改画面标题、解说词、字幕；「AI 改写」按要求重写当前这句；也可以写「给 AI 的备注」，让后续生成解说时参考
- 取消勾选「包含在视频中」可以跳过误操作的步骤
- **不用渲染整个视频，先看某几页**：**▶ 回放本页**（预览上方，或者每张卡片上的小 ▶）把这一页按成片的效果渲染成一个 720p 的小视频再播放 —— 动画、配音、字幕、页里的视频都在。所有页都能放，包括浏览器自己放不了视频格式的页（wmv、avi、部分 mov / mkv）。左栏上方的 **▶ 连播** 可以勾选几页连续观看（Shift 连选一段、「全选」、「从当前页起」），播到哪一页，列表里那一页就高亮。**■ 停止播放**（或按 Esc）停下播放器，还在生成的回放也一并取消。回放不会动真正的成片和字幕文件，项目的 `preview` 文件夹里只留最近 3 个

**3. 生成**

底部操作条从左到右：

- **⚡ 一键生成** —— 解说 → 配音 → 渲染，一条龙
- **① 生成解说** —— 只让 AI 模型写脚本（可选风格、目标观众）
- **② 合成语音** —— 只给还没配音的步骤配音
- **③ 渲染视频** —— 合成 MP4
- **🌐 翻译** —— 整套脚本换语言，并自动换成该语言的音色
  - 网页录制的项目：把现有解说翻译成目标语言
  - PPT 项目：幻灯片页**不翻译**现有解说，而是按 PPT 原文（页面文字 + 演讲者备注）直接用目标语言重写，标题和片头片尾一起重写。避免「英文 PPT → 中文解说 → 再翻回英文」这种二次翻译，说法和术语都跟原文一致。选的是「备注原文就是解说」时，换语言会改为「AI 参考备注改写」（备注是原来的语言，不能照念）；自己录音的页改成 AI 朗读；插入的视频步骤没有 PPT 原文，照常翻译；AI 漏写的页自动退回翻译
- **导出** —— Markdown 图文文档 / 脚本 JSON / SRT 字幕

渲染大致是成片时长的 0.2～0.5 倍（1080p30；PPT 项目更快）。默认会并行渲染并自动使用显卡编码，详见[渲染速度（显卡加速）](#渲染速度显卡加速)。

**中途停止**：任务运行时进度条右边会出现 **■ 停止**，一般 1 秒内停下。已经做完的部分会保留：

| 停在哪个阶段 | 保留什么 |
|---|---|
| 生成解说 | 不写入半截结果（AI 请求当场放弃，不用等它返回；Claude 会直接断开流式连接，不再继续计费） |
| 合成语音 | 已经配好音的步骤保留配音 |
| 渲染视频 | 上一次导出的成片原样保留，不会被半截文件覆盖 |

改完再点 **⚡ 一键生成** 就是接着做：每一步都已有解说时不再调用 AI 模型，只给改过文字的步骤重新配音，然后渲染。

## 语音输入

语音识别用本机的 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)，**录音不离开这台电脑**。

### 1. 边录边讲

录制前在扩展弹窗里勾上 **🎙 边录边讲**，然后边操作边讲解就行。停止录制后：

1. 整段录音上传给本机服务
2. 识别成文字，去掉「嗯 / 啊 / 呃」和口吃重复
3. **按你每次点击的时间，把每句话分给对应的步骤** —— 规则是「先说后点」：一句话属于它之后发生的第一个操作
4. 按你选的方式出配音：
   - **讲完转成 AI 配音**（默认）：你的话变成解说词，由 AI 音色重新朗读，口误和停顿都没了
   - **保留我的原声**：按步骤把你的录音切片，字幕按词级时间戳对齐

编辑器打开时会自动接上识别进度，识别完步骤里就有解说了。

首次使用会弹出麦克风授权页（扩展的后台页面没法直接弹权限框，要先授权一次）。之后在弹窗「麦克风设置」里可以换设备、看音量条。

### 2. 单步录我的声音 / 上传音频

右栏 **配音** 卡片：

| 按钮 | 作用 |
|---|---|
| 🎙 录我的声音 | 弹出录音器：选麦克风、选识别语言、最长 60 秒、回放、重录 |
| ⬆ 上传音频 | mp3 / wav / m4a / webm，15 MB 以内 |
| 改用 AI 配音 | 保留识别出的文字，丢掉录音，自动用 AI 重新念 |
| 删除 | 删配音，文字保留 |

原声步骤有两个保护：
- 改解说词（比如修正识别错字）**不会**作废录音
- 「② 合成语音」和「生成解说」都**不会覆盖**原声；翻译后才会自动切回 AI（原声是原语言）

底部 **🎙 ▾** 菜单里有批量操作：全部改用 AI 配音 / 删除所有配音。

### 3. 口述转文字

解说词输入框右上角 **🎤 口述**：对着麦克风说，识别结果追加进解说词，不保留音频。适合懒得打字的时候。

### 识别模型

⚙ 设置 → AI 与语音 → 语音识别：

| 模型 | 大小 | 说明 |
|---|---|---|
| tiny / base | 75 / 145 MB | 快，中文准确度一般 |
| **small** | 465 MB | **默认**，中文日常讲解基本不出错 |
| medium / large-v3 | 1.5 / 3 GB | 更准，CPU 上明显更慢 |

第一次识别时自动下载到 `~/.cache/huggingface`，之后离线可用。在普通 CPU 上 small 模型大约 2~3 倍实时速度（10 秒录音 4~5 秒识别完）。

**在中国大陆 / 公司网络下载不了模型**

- **自动换源**：先试 HuggingFace 官方源，连不上（几秒内就能判断）自动改用国内镜像 `hf-mirror.com`，不用设置。进度条会显示正从哪里下、下了多少 MB。也可以在「模型下载源」里填自己的镜像，会排在最前面
- **离线放置**：完全不能联网时，把模型文件夹放到程序旁边的 `models\faster-whisper-<型号>\`（exe 版就是 `StepCast.exe` 旁边），里面要有 `model.bin`、`config.json`、`tokenizer.json`、`vocabulary.*`。程序会优先用这里的，不再联网。模型文件可以从已经下好的电脑上拷：在 `%USERPROFILE%\.cache\huggingface\hub\models--Systran--faster-whisper-<型号>\snapshots\<一串字符>\` 里
- **打一个带模型的包**：`build_exe.bat --with-model` 会在普通压缩包之外，再打一个 `StepCast-<版本>-win64-with-model-small.zip`，里面已经放好了 small 模型（大约多 450 MB），发给国内同事解压就能离线识别。要别的型号就写 `--with-model medium`

> 以前版本里「模型镜像」这一项其实没有生效（下载地址在程序启动时就被固定了），现在已经修好。

## PPT / PDF 转视频

**项目 → 📊 从 PPT / PDF 创建**：

1. **上传** .pptx / .ppt / .pdf（最多 100 页）
2. **选页**：缩略图网格，默认选中所有非隐藏页；有备注的页带「备注」标记，没备注的页带橙色「无备注」
3. **解说从哪来**（PPT 里写了备注时才出现）：

   | 选项 | 行为 | 是否联网 |
   |---|---|---|
   | 备注原文就是解说（推荐，默认） | 备注一字不改作为解说词和字幕，只把换行并成一段；备注和解说不是同一种语言的页，交给 AI 用解说语言完整地讲出来 | 同一种语言的页不调 AI 模型 |
   | AI 参考备注，改写成口语 | 以备注意图为主、页面文字为辅，AI 重写成讲师旁白 | 调 AI 模型 |
   | 不用备注，AI 按页面内容写 | 只根据标题和页面文字写 | 调 AI 模型 |

4. **没有备注的页**（选了「备注原文」且有页面没写备注时出现）：
   - **AI 按页面内容补写** —— 只把这几页的标题和页面文字发给 AI 模型，有备注（且和解说同一种语言）的页不外发
   - **留空，我自己补** —— 全程离线；这些页不配音，进编辑器后在右栏补上解说再点「生成语音」
5. **详细程度**：简要（每页 1~2 句）/ 标准（2~4 句）/ 详细（4~7 句）—— 只影响 AI 写的页，全部用备注原文时自动变灰
6. 选解说语言和音色（可以和 PPT 原文语言不同），生成

> **PDF 没有演讲者备注。** PowerPoint 另存为 PDF 时不会把备注带进去，所以导入 PDF 只能让 AI 按页面内容写解说。想用备注作标准解说，请直接导入 `.pptx` / `.ppt`。
> 备注读取兼容 Google Slides / Keynote 导出的 PPTX（备注写在普通文本框里而不是标准占位符里的情况）。

**导入以后再换备注用法**：PPT 项目里点「生成解说」，弹窗里同样有「解说从哪来 / 没有备注的页 / 详细程度」三项（录屏项目显示的是风格和目标观众）。选「备注原文」时默认勾上「覆盖已手动编辑过的解说」，因为备注本身就是你认定的标准稿；在编辑器里改过某页的「演讲者备注」后，再点「生成解说」或「一键生成」就会用改过的备注。这个选择会记在项目里，之后「一键生成」沿用它。

每页变成一个步骤，视频里是页面居中 + 轻微推近 + 翻页淡入，字幕在页面下方不压内容。PPT 自己的切换效果不会保留；页面里的动画在本机装有 PowerPoint 时按 PPT 里设的来（见下面「有 PowerPoint 动画的页」）。进编辑器后可以改每页的解说、演讲者备注，也能给某一页录原声。

### 幻灯片里的视频

PPT 页面里嵌的视频会保留下来：导入时每个视频变成一个单独的「视频」步骤，紧跟在它那一页后面（缩略图上有「视频」标记，导入对话框里可以关掉「包含幻灯片里的视频」）。

- **默认**：先念完这一页的解说，再在幻灯片上**原来的位置**播放视频、放**视频原声**；PowerPoint 里设的剪辑起止点也会沿用
- **先播视频**：有些页的讲解提示是叠在视频上、视频播完才出现的。选中这一页，把「这一页和视频的播放顺序」改成「先播放视频，播完再讲叠在视频上的文字」：先播视频，叠在视频上的文字（一半以上面积在视频框里）这时先藏起来；播完后画面停在视频最后一帧，这些文字随解说一条条出现在视频画面上（关掉「逐条出现」时是很快依次出现），页面上其他内容一开始就在。「① 生成解说」这时只讲叠在视频上的文字，改了顺序后请重新生成。藏文字要用到导入 PPT 时生成的「逐条出现」数据（见下一节）；没有的话，视频播完后整页一起显示
- 在编辑器里点这个视频步骤，右栏「视频」可以改：
  - **播放方式**：在幻灯片原位置播放 / 全屏播放 / 只显示封面（不播放）
  - **截取**：从第几秒到第几秒。中间的播放器可以拖动进度条，找到位置后点「⏱ 当前位置」
  - **声音**：播放视频原声，或者视频静音、念这一步的解说词（解说比视频长时画面停在最后一帧）
  - **🎤 视频里的讲话转成字幕**：用本机语音识别把视频里讲的话写进「字幕」，按讲话时间对齐（之后再改截取起止点，字幕照样对得上；翻译项目时这段字幕也会翻译，声音保持原声）
- 播视频原声时，这一步的解说词不会被念出来，「生成解说」也不会去改它；要显示字幕就写在「字幕」里
- **取不到的视频**：视频不是嵌在 PPT 里、而是链接到作者电脑上的文件，或者是在线视频（YouTube 等）时，导入后这一步先不放进成片，右栏会提示；把视频文件上传上去（「⬆ 上传视频文件」）就自动加进来
- PDF 里没有视频（PowerPoint 另存为 PDF 时视频就丢了），要保留视频请导入 `.pptx`

录屏教程里也能插视频：左栏上方的 **🎬 ＋** 把一段视频插在当前这一步后面（全屏播放），比如一段产品演示或宣传片。手机竖着拍的视频、浏览器或录屏软件直接录的 webm 都可以；插入时会取一帧当这一步的封面。

### 逐条出现，突出当前讲的内容

导入 PPT 时勾选「逐条出现，突出当前讲的内容」（默认勾选），每页的正文就不再一开始全部显示：

- 标题区、页码一直显示；正文按阅读顺序分成几条，**解说说到哪一条，那一条才淡入出现**
- 讲到下一条时，前面讲过的变淡，突出当前这条；同一句话里讲到的几条一条接一条出来，互相不变淡；这一页快结束时全部恢复正常亮度
- 翻页时从上一页淡到下一页（不闪黑），停一拍（0.35 秒）再开口，字幕跟着配音一起出现

出现的时机怎么定：

- **配了 AI 时**：渲染前（以及点「▶ 回放本页」之前，所以没渲染过的页回放时时间也是对的）让 AI 把每一条和解说里讲到它的那一段对上（按意思对，解说和页面不是同一种语言、解说是意译都行），条目在讲到它的那一段开头出现，顺序跟着解说走。很长的句子会在逗号处再切开来对，一句话里列了好几样东西（「钢笔、尺子、橡皮……」）时，是一样一样对上，而不是都挤在句首。解说里没讲到的条目排在前后两条之间依次出现；一条都没对上时，翻页后依次快速出现。结果存在项目里，解说和页面都没变的页下次渲染不再问 AI；只有打开了逐条出现的页才会去对
- **没配 AI 时**：在解说里找这一条的原文。一半以上找得到，就按找到的位置出现；大多找不到（比如英文页面配中文解说）就在翻页后依次快速出现、不突出当前 —— 不知道讲到哪了，与其乱放不如一开始就摆好
- 没有文字的图片跟离它最近的文字条目一起出现
- 用 AI 写解说时，每页的内容条目（按阅读顺序）会一起交给 AI，让它按页面顺序讲、讲到每一块时点出关键词，出现顺序和讲的顺序自然一致

怎么分条：

- 卡片式排版：同一张卡片里的底框、编号、标题、说明算一条，卡片之间的箭头跟后一张卡片一起出现
- 传统要点：一个文本框里的每条一级要点（连同它的下级要点）算一条
- 阅读顺序：先分行、再分栏 —— 一行卡片从左到右，左右两栏先读完左栏再读右栏；小标题跟它下面的第一条一起出现
- 这些页整页一起出现：只有一条内容的页、超过 12 条的页、打了码的页；封面（第 1 页且字很少）默认整页出现，需要时可以在编辑器里打开这一页的开关

在编辑器里点一页幻灯片，右栏「幻灯片内容」下面可以：

- **整个项目**开关：「幻灯片逐条出现，突出当前讲的内容（整个项目）」
- **这一页**开关：「这一页逐条出现」—— 流程图这类排版复杂的页可以单独关掉

#### 有 PowerPoint 动画的页

作者在 PowerPoint 里给这一页设了动画时，StepCast 直接按**他设的动画**来，不再靠版面猜：

- **一步 = 一次点击**。动画里每点一下算一步，像上面的「一条」一样对齐解说；一步里面保留 PowerPoint 自己的时间关系：「与上一项同时」的一起出现，「在上一项之后」和延迟照原来的先后（比如角标在卡片淡入后半秒出现，提示 2 秒后又消失）
- **文字和它后面的背景**：没有入场动画的（文字后面的卡片、标题、页面背景）从一开始就在；每个有动画的形状（按段落出现的文本框是每一段）单独导成一张透明图层，所有图层严格按 PowerPoint 里的**上下层次**叠放：卡片比它上面的文字晚出现，也仍然在文字后面；没有动画、盖在动画卡片上面的标签，也仍然盖在上面。每个图层分别在黑底和白底上各导一次，文字边缘准确，放在什么背景上都不会有杂边
- **入场和退出**：「出现」（以及短到看不出来的效果）是瞬间出现；「擦除」从 PPT 里设的那一边露出来，「飞入」从那一边或那个角滑进来，其他入场效果淡入并轻微上浮；设了退出的元素在 PowerPoint 设定的时间离开
- **动作路径**：先出现、再沿着一条线移动 2 秒的光点，就按 PowerPoint 设的时长和缓入缓出这样移动。直线、曲线、闭合的形状都行，包括 PowerPoint 内置的各种路径。强调效果（陀螺旋、脉冲、变色）不处理
- **出现的先后就是作者点击的顺序**：不管解说先提哪一条，画面上的步骤都按作者的点击顺序出现（前后至少相隔半秒），写解说的提示词也会要求 AI 按动画顺序讲。讲后面的步骤时，前面的内容往页面背景色变暗，但仍然不透明，所以后面的卡片不会透出来
- **视频后出现的提示**：作者让提示在视频播放之后出现（动画列表里排在「播放」之后）时，这一页导入后自动选「先播放视频」：先播视频，再随解说把提示一条条放在视频最后一帧上，AI 写解说时也只讲这几步
- 没有入场动画的页、超过 40 个图层的页仍然按上面的版面分组；有动画的封面也会逐步出现

需要本机装有 PowerPoint：导入时用它把每页多导出几张图（正文隐藏的底图、每一条单独的样子），所以导入会慢一些，大约每页多 1 秒。渲染时不需要 PowerPoint，项目拷到别的电脑上照样有效果。没有 PowerPoint、或者导入的是 PDF 时，这个选项不出现，所有页整页一起出现。幻灯片不推镜，画面只在条目出现、变淡的那一刻变化，渲染速度基本不受影响。

### 两人问答

导入 PPT 时「讲解方式」选「两人问答（主持人提问、讲师讲解）」，整个视频就由一位主持人（女声）和一位讲师（男声）对话来讲：

- **台词完全依据页面内容**（标题、正文、演讲者备注），**不因为是对话就压缩**：讲师讲的信息量不少于一个人单独讲这一页，主持人的提问、追问、小结是额外加的。篇幅按「详细程度」来（标准档一页内容页大约 220~380 字的台词），封面、过渡页可以短
- **像两个同事在聊，不是一问一答的考试**：主持人接着讲师的话往下问、用自己的话复述、提出学员常见的疑问；讲师举例子、打比方、给实用建议；节奏有变化，新的一页从上一页的话题自然接过来。第一页主持人开场，最后一页主持人收尾
- **和「逐条出现」配合**：页面上有几块内容，讲师就按阅读顺序一块一块讲（每块单独讲到），条目在讲到它的那句话出现
- **名字不念、不上字幕**：名字只在编辑器里区分是谁说的；AI 偶尔写上的「晓晓：」这类前缀、对名字的称呼会自动去掉
- **两种音色**：默认主持人女声、讲师男声（中文晓晓 / 云希，英文 Aria / Guy……），导入时可以选；每句用说话人的音色合成，接话停顿 0.22 秒
- **画面和单人讲解一样**：幻灯片大小不变，只是声音换成两个人；字幕一句一条，不会跨两个人
- 片头片尾、没有台词的解说（比如插入的视频步骤）由主持人念

编辑器里：

- 右栏「问答台词」一句一行：点名字按钮换成另一个人说，▶ 试听这一句，↑ 调顺序，✕ 删除，下面的按钮加一句；「AI 改写」改写的是整页的对话
- 底部「🎭 讲者」：改名字、换音色。换了音色的人说过的台词会作废旧配音，点「② 合成语音」重新配
- 「🌐 翻译」换语言时，两位讲者一起换成目标语言的音色（自己起的名字保留），台词按 PPT 原文用目标语言重写成对话
- 导出的图文文档写成「**名字**：台词」

两人问答没有「备注原文就是解说」这一项：备注是一个人讲的稿子，没法原样拆成两个人的对话，会作为参考交给 AI。

**幻灯片画面怎么导出的**：检测到本机 PowerPoint 时用它原样导出（字体、图表、SmartArt 都和你看到的一样），`.ppt` 老格式也支持；装了 LibreOffice 时用它；都没有时 PDF 照常，PPTX 退化成只有文字的简版页 —— 建议先另存为 PDF。

## 敏感信息打码

录内部系统时最怕截图里带出客户名、邮箱、手机号。这里有三层保护。

### 1. 录制时自动识别（默认开）

扩展在每次截图的同一瞬间遍历页面 DOM，用 `Range` 拿到**每个命中子串的精确矩形**，所以打的码正好盖住那几个字，不会糊掉半个页面。

识别范围：

| 类型 | 怎么认的 |
|---|---|
| 邮箱 / 手机号 / 身份证 / 银行卡 / IP | 正则 |
| 人名 | 「姓名：张三」这类带标签的；**以及表格里「姓名 / 联系人 / 负责人」那一列的单元格** |
| 自定义词 | 扩展设置里填的词表（如客户名、内部代号） |
| 输入框的值 | 命中规则时整个框打码 |

在扩展弹窗 → 设置里可以关掉，或补充「额外要打码的词」。

> 表头判断比猜姓氏靠谱得多 —— 「任务」「付款」「方式」的首字也都在百家姓里，靠猜会把后台界面糊成一片。

### 2. 编辑器里手动补

点中间上方的 **🔒 打码**，就能在截图上：

- 空白处拖动 = 新建打码框
- 拖框身 = 移动，拖右下角 = 缩放，点 × = 删除
- 右栏列出这一步所有框，点方式按钮在 **模糊 / 像素化 / 纯色块** 之间切换

### 3. 事后全项目扫描

右栏 → **全项目扫描…**，可以：

- 按内置规则重新扫一遍
- 输入一批关键词（客户名、项目代号…），**一次性打掉所有步骤里的所有出现**
- 开启「裸的中文短名」（会误报，谨慎用）
- **清除自动打码**：一键撤销所有自动框，手动画的保留
- **清空文字索引**：删掉本机为了支持关键词扫描而记录的页面文字

> 只对新录制的内容有效 —— 这个功能之前录的项目没有文字索引，只能手动框选。

打码是**在源截图上降采样**做的，信息真的被丢掉了，不是盖一层遮罩；后续的放大镜头也不会把它还原出来。

扫描时命中的内容还会同步从 `page_title` / `element_text` / 输入值里抹成掩码 —— 这三项是唯一会发给 AI 模型的字段。

## 渲染速度（显卡加速）

生成视频分两步：用 Pillow 在 Python 里**一帧一帧画**，再把画面送给 ffmpeg 编码。网页录制项目的瓶颈是画帧；PPT / PDF 项目大多数帧可以复用，
画帧很便宜，时间主要花在把画面送进 ffmpeg 并编码上（显卡编码在这里帮助最大）。下面三件事是一起做的，默认全部打开，不用设置：

| 做法 | 说明 |
|---|---|
| 并行渲染 | 每一步（含片头片尾）是独立的一段，同时渲染多段。Pillow 画图时会放开 GIL，多线程能真正跑满多核。默认按 CPU 核数自动，最多 4 段 |
| 静态画面复用 | 画面没变化的帧直接复用上一帧的数据，不重画。PPT / PDF 项目每页只有翻页动画和字幕在变，收益很大 |
| 显卡编码 | 自动检测 NVIDIA（NVENC）、Intel 核显（QSV）、AMD 独显和 Ryzen APU 的集成 Radeon（AMF），能用就用，省下 CPU 给画帧。检测是真的编一小段试试，不是只看支持列表：驱动太老、虚拟机里没显卡、画质参数名对不上（AMF 常见，会改用编码器默认参数重试）都能识别。自己装的 ffmpeg 比显卡驱动新时（比如 ffmpeg 7.1.1 的 NVENC 要 NVIDIA 570 以上驱动），会改用程序自带的 ffmpeg 做显卡编码。同时渲染几个项目时显卡编码排队使用，不会超出显卡的同时编码上限。实在用不了，或编码中途出错，自动退回 CPU |

实测（8 核台式机，1920×1080@30，用包里自带的 ffmpeg）：

| 项目 | 改进前 | 现在 | 提速 |
|---|---|---|---|
| PPT 幻灯片（9 页，成片 2 分 36 秒） | 164 秒 | 22 秒 | 7.6x |
| 网页录制（8 步，成片 68 秒） | 59 秒 | 30 秒 | 2.0x |

另一台机器（4 核 8 线程的 i7-4790K + GTX 1650 SUPER）：8 页动画页、成片 3 分 33 秒，显卡编码 36 秒（约 6 倍速），纯 CPU 50 秒。

画面内容逐像素比对过，并行和串行的结果完全一致。

**想手动控制**，改 `config.json`（编辑器里没有这两个设置）：

```json
{
  "video_encoder": "auto",
  "render_workers": 0
}
```

- `video_encoder`：`auto`（默认，有显卡就用）/ `cpu` / `nvenc` / `qsv` / `amf`。显卡编码的文件通常比 CPU 大三到五成，想要更小的文件就设成 `cpu`
- `render_workers`：同时渲染几段，`0` = 自动。内存紧张就设 `1` 或 `2`（每段渲染大约占 30 MB）

还嫌慢就降分辨率或帧率：右上角 ⚙ 设置 → 视频风格，1280×720 比 1920×1080 快一倍以上，25 帧比 30 帧再省一些。

**配音**也是几段一起做：免费的 Edge 音色一次 3 段，付费服务一次 2 段（它们按套餐限制并发请求）。12 段的测试里从 18.8 秒降到 3.9 秒。想改就在 `config.json` 里设 `"tts_workers"`（`0` = 自动，`1` = 一段一段做）。点「停止」时已经做完的段（和正在做的段，做完后）会保留，不再开始新的；每一段的音频和它的时间信息总是一起更新，所以停在重新配音的中途，也不会出现新音频配旧字幕时间。问答项目每页内部本来就在并行，所以页与页之间还是一页一页做。

## 第二语言字幕（外挂，看的人自己选）

主字幕烧在视频里；第二语言字幕是单独的字幕文件，紧贴在主字幕下面、字小一些，**看视频的人自己选一种，默认不显示**。先渲染视频，需要哪些语言再生成，可以一次生成好几种，以后随时加。

1. 渲染视频：主字幕底边在画面高度的 93.5%，下面留一行给第二字幕（设置 → 视频风格 →「给第二语言字幕留位置」，默认打开；关掉时主字幕在 95.5%）。主字幕的底框紧贴文字（一行高 5.5%）；幻灯片上沿离画面顶边只留 1.2%，下沿到 87.5%（关掉时 89.5%）。第二字幕的底框紧挨着主字幕的底框，默认斜体（阿拉伯文从右往左写，不用斜体）
2. 点「查看视频」（或者「导出」菜单里的「第二语言字幕 / 网页播放包…」），点橙色的「🌐 生成第二语言字幕」，勾选语言后「开始生成」：主字幕按整句合并后由 AI 翻译（你在设置里选的那家），每句用这句话在视频里的时间；太短的句子并进下一句，太长的译文拆成两条
3. 「预览」下拉框里选一种，在编辑器里直接看效果（⛶ 全屏时第二字幕也在）
4. 每种语言都能单独下载 **VTT / SRT**；**下载网页播放包** 得到一个 zip：视频 + 各语言的字幕 + 播放页 `index.html`
   - **SRT 给本地播放器用**（Windows Media Player 等）：这类播放器显示外挂字幕会慢半拍，SRT 里整条时间轴提前了 0.25 秒；**VTT 给网页播放器用**，时间和视频完全对齐

**放到公司内部网页上**：把网页播放包解压到网站的某个目录，直接打开 `index.html`，或者在页面里用 iframe 嵌进去（要全屏的话加 `allow="fullscreen"`），自己的页面不用改别的：

```html
<iframe src="/training/demo/index.html" width="960" height="600" allow="fullscreen" style="border:0"></iframe>
```

- 播放页右下角 💬 选第二字幕（默认「—」不显示），⛶ 全屏；链接后面加 `?sub=en-US` 可以直接打开某种第二字幕
- 字幕的时间轴都写在播放页里，不需要网站额外配置；直接双击打开也能用
- 想用自己的播放器：用下载的 VTT 文件（`<track kind="subtitles" srclang="en" label="English" src="….en-US.vtt">`，不加 `default` 就是默认不显示）。VTT 里已经写好放在最底下一行、字号小一些，不过不同播放器的显示效果不完全一样，播放页最准
- 视频重新渲染过（解说改了），之前生成的第二字幕会标成「需要重新生成」，播放包里不会放过期的字幕
- 老版本渲染的视频没给第二字幕留位置，两种字幕可能叠在一起，会提醒你重新渲染一次

## 解说语言和第二字幕语言

解说语言（新建项目、导入 PPT、翻译、Chrome 扩展「边录边讲」）和第二语言字幕用同一张语言表，共 46 种，每种都有 Edge 的免费配音（一女一男，双人问答时男声做讲师）。下拉框里的顺序：

1. **中文**：简体中文、繁體中文
2. **欧洲语言**：常用的在前 —— English (UK)、English (US)、Deutsch、Français、Español、Italiano、Nederlands、Polski、Português (Portugal)；其余按本地名的字母排 —— 波斯尼亚语、加泰罗尼亚语、捷克语、威尔士语、丹麦语、爱沙尼亚语、爱尔兰语、加利西亚语、克罗地亚语、冰岛语、拉脱维亚语、立陶宛语、匈牙利语、马耳他语、挪威语、罗马尼亚语、阿尔巴尼亚语、斯洛伐克语、斯洛文尼亚语、芬兰语、瑞典语、土耳其语，然后希腊语和用西里尔字母的保加利亚语、马其顿语、俄语、塞尔维亚语、乌克兰语
3. **其他语言**：日本語、한국어、Português (Brasil)、Tiếng Việt、ไทย、العربية、हिन्दी

- PPT 备注的语言和解说语言不同时（比如英文备注、瑞典语解说），备注不会原样照念，而是由 AI 参考备注用解说语言来写。丹麦语 / 挪威语 / 瑞典语、捷克语 / 斯洛伐克语这类近亲语言分不太清，算作同一种（照念）
- 语音识别（边录边讲、视频讲话转字幕）支持这些语言里的绝大多数；爱尔兰语模型不认识，会让模型自己判断
- 第二语言字幕默认斜体，和主字幕一眼分开（阿拉伯文从右往左写，不用斜体）

## 多语言字幕（阿拉伯语、印地语、泰语……）

视频里的字幕、片头片尾、步骤标题都是程序画进画面的，所以各种文字都要自己处理好：

- **自动挑字体**：默认用微软雅黑，但它没有阿拉伯、希伯来、印地、泰、韩文，也缺越南语的部分字母（以前画出来是方块）。现在按文字里实际出现的字，自动换成 Windows 自带的、有这些字的字体（Segoe UI、Nirmala UI、Leelawadee UI、Malgun Gothic 等）。中文、日文、英文照旧用微软雅黑，观感不变
- **复杂文字交给 Windows 排版**：阿拉伯文要连写、从右往左排；印地文有连字，元音符号要挪到辅音前面；泰文的声调要叠放。这些由 Windows 自带的排版引擎（Uniscribe）完成，每台 Windows 电脑都有，不用另外安装。括号、引号的方向也按从右往左的规则自动处理
- 在 ⚙ 设置里指定了字体的，优先用你指定的字体，缺字了才换

非 Windows 系统上会退回 `arabic-reshaper` + `python-bidi`：阿拉伯文、希伯来文能正确显示，印地文、泰文不出方块但排版不完全正确。

`.srt` / `.vtt` 字幕文件由播放器自己排版，一直是正常的。

## 视频风格设置

**⚙ 设置 → 视频风格** 里可调：

| 项 | 默认 | 说明 |
|---|---|---|
| 分辨率 / 帧率 | 1920×1080 / 30 | 支持 720p、2K、竖屏 1080×1920 |
| 主题色 | `#FF5C39` | 高亮框、涟漪、序号角标的颜色 |
| 自动放大 | 开 | 推近到操作区域，倍数可调（1.0 = 关闭运镜） |
| 高亮区域外变暗 | 开 | 关掉后页面保持原始亮度 |
| 鼠标指针动画 | 开 | 指针从上一步位置飞向本次点击点 |
| 浏览器外框 | 开 | 给截图加一层带地址栏的窗口外框 |
| 烧录字幕 | 开 | 关掉后画面无字幕，但仍导出 `.srt` |
| 每步最短时长 | 2.5 秒 | 实际时长 = max(此值, 配音时长 + 留白) |

单步还能在右栏单独关掉放大 / 高亮，或写死时长。

## 常见问题

**扩展显示「未连接」**
先运行 `run.bat`。若改过端口，在扩展弹窗的「设置」里把服务地址改成一致。

**截图里出现了「● 录制中」浮层**
正常情况下截图前会自动隐藏。如果偶发漏网，删掉该步重录，或用 `Alt+Shift+S` 补一张。

**点击很快连续操作，有几步截图对不上**
Chrome 限制截图频率约每秒 2 次，扩展已做排队限流。操作太快时后面的截图会稍微滞后 —— 放慢一点点操作节奏效果最好。

**高亮框位置偏了**
在编辑器中间直接拖动橙色框调整，拖右下角小方块改大小，松手即保存。

**iframe 里的操作没被记录**
扩展只监听顶层页面，嵌套 iframe（如部分支付、验证码组件）内的点击不会被捕获。用 `Alt+Shift+S` 手动补截图，再自己写解说。

**配音失败**
edge-tts 需要联网。断网时会自动退回 Windows SAPI5 离线语音（音质一般且没有时间轴对齐）。

**中文显示成方块**
渲染用的是系统字体，默认找 `C:\Windows\Fonts\msyh.ttc`（微软雅黑）。缺失时可在 `config.json` 里设 `font_path` 指定一个中文 TTF/TTC。

**打开编辑器提示 403「只允许通过 127.0.0.1 / localhost 访问」**
服务只接受本机访问，并拒绝来自其他网站的请求——否则你浏览的任何网页都能在后台读你的截图、改设置。如果确实要在局域网里用另一台电脑访问，启动前设置允许的主机名：

```bash
set VT_ALLOWED_HOSTS=192.168.1.20
python app.py --host 0.0.0.0
```

**边录边讲没有录到声音**
扩展弹窗 → 麦克风设置，确认已授权、选对了设备、说话时音量条会跳。弹窗里如果显示红字「麦克风未授权」，点一次授权即可，已录的步骤不受影响（只是这次没有语音）。

**识别出繁体字 / 错字**
已经用简体提示词引导，极少数情况仍可能出现；直接在解说词里改就行，原声步骤改文字不会丢录音。同音字（登录 / 登陆）属于识别模型本身的局限，换 medium 模型会好一些。

**PPT 导入后画面是文字简版**
说明没检测到 PowerPoint / LibreOffice。在 PowerPoint 或 WPS 里「另存为 PDF」再导入即可；PDF 不带演讲者备注，所以想用备注作解说又没有 PowerPoint 时，可以装 LibreOffice（画面导出更好），或者接受文字简版画面、导入 PPTX 选「备注原文就是解说」。

**渲染太慢**
降到 720p、帧率 24，或关掉「自动放大」（省掉每帧的缩放重采样）。

## 隐私说明

截图、音频、视频、脚本全部只存在本机 `projects/` 目录。只有下面这些操作会把文字发给你在设置里选的 AI 服务商（选本地 Ollama 则完全不出本机）：**生成解说 / 翻译 / AI 改写**；**生成第二语言字幕**（发送主字幕的文字）；幻灯片打开「逐条出现」时**渲染视频或回放**（发送每页的解说和页面上各条的文字，让 AI 标出讲到哪一条；没配 AI 时改用文字匹配，不联网）。发送的内容对每家服务商都一样。配音时，解说文字会发给你选的配音服务（默认微软 Edge；选了豆包 / MiniMax / 通义 / Gemini / ElevenLabs / Azure 的音色就发给那一家）。

**想确认到底发了什么，直接打出来看**（拦截请求、不真的发送，不消耗额度、不需要 Key）：

```bash
python tools/dump_llm_payload.py
```

会逐字打印三个调用点的完整请求体。概括：

| 每一步发送 | 来源 | 截断 |
|---|---|---|
| `action` | 点击 / 输入 / 按键 / 跳转 | — |
| `page` | 页面标题 | 80 字 |
| `url` | **只有域名 + 路径**，scheme / 查询串 / 锚点全部丢掉 | 60 字 |
| `element_text` | 你点的那个元素上的可见文字 | 80 字 |
| `element_role` | button / link / textbox … | — |
| `typed` | 你在输入框里打的内容（仅输入类步骤） | 60 字 |
| `user_note` | 你自己在编辑器里写的「给 AI 的备注」 | 200 字 |

**从不发送**：截图、音频、成片、CSS selector、元素坐标与尺寸、页面 HTML/DOM、Cookie、localStorage、时间戳、页面上其他没被点过的文字。

⚠️ 需要自己判断的地方：`element_text`、`page`、`typed` 是**页面上的真实文字**。如果你点的是「客户张三」这一行，或者标题是「订单 #12345」，这些字就会进请求。

可控手段：

- 跑一遍[敏感信息打码](#敏感信息打码)的扫描 —— 命中的内容会同时从这三个字段里抹成掩码，之后再点 AI 按钮就是干净的
- 取消勾选「包含在视频中」的步骤，**不会**进任何请求（生成解说和翻译都跳过）
- 完全不点那三个按钮，自己手写解说词 —— 配音和出片照常工作，全程离线（除 TTS 外）
- 密码框，以及 name/id/autocomplete 里含 `pass`/`pwd`/`secret`/`token`/`cvv`/`card` 的输入框，扩展**在录制阶段**就替换成 `••••••••`，本机存的也是掩码

配音时解说词文本会发给微软 Edge 的语音服务（`edge-tts`，无需账号）。

**语音输入**：你的录音只在本机识别（faster-whisper），不上传到任何云服务。唯一的联网是第一次下载识别模型。

**PPT 导入**：幻灯片图片不外发。选「备注原文就是解说」时，备注和解说是同一种语言的页完全不联网；没备注的页选了 AI 补写才会把**那几页**的标题和页面文字发给 AI 模型（不含备注）；备注是另一种语言的页（比如英文备注、中文解说）会把标题、页面文字和备注发给 AI，用解说语言讲出来；选「AI 参考备注改写」会发送选中页的标题、页面文字、演讲者备注 —— 导入向导底部会实时提示这次会发什么。

## 已知限制

- 只捕获顶层页面（不含 iframe）。
- 不录制视频流，是「截图 + 动画」的方式 —— 所以拿不到页面里的动画过程，但文件小、画面干净、可逐句编辑。
- 扩展只在 `http(s)` 页面工作，`chrome://` 等内部页面无法截图。
- 目前为单人本地使用，没有账号和多人协作。
